# Root Module: dundemo

## 1. 개요

이 디렉토리는 dundemo 애플리케이션을 구동하기 위한 모든 핵심 인프라 모듈을 포함하고 관리합니다. 각 하위 디렉토리는 특정 목적을 가진 모듈로 구성되어 있으며, 전체 인프라의 기반이 됩니다.

---

## 2. 모듈 구성

- **`VPC/`**: 애플리케이션이 배포될 격리된 네트워크 환경을 구성합니다. (VPC, Subnet, IGW, NAT Gateway 등)
- **`db/`**: 애플리케이션의 데이터를 저장하기 위해 인스턴스를 생성하고 DB를 설치합니다.
- **`S3/`**: 백엔드 빌드 파일을 저장하기 위한 S3 버킷을 관리합니다.
- **`app_back/`**: 백엔드 애플리케이션을 실행할 EC2 인스턴스와 관련 리소스를 정의합니다.
- **`app_front/`**: 빌드된 프론트엔드 파일을 S3에 배포하고, CloudFront를 통해 전 세계 사용자에게 빠르게 제공하기 위한 인프라를 정의합니다.
